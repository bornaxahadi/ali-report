# BYD Seal 05 DM-i sourcing report (English / فارسی)

A phone-friendly report for Mr. Ali, served by GitHub Pages.

- `index.html` is the app. It reads `data.json` and refreshes every 5 minutes.
- `data.json` is written by the sourcing agent: `suppliers`, `meta`, `log`, `instructions`.
- "Tell the agent what to do" opens a GitHub issue labelled `instruction`. The agent reads open instruction issues on each run and replies there.

Note: this repository and its Pages site are public.
